# Pulse Line 发布流程

## 前置条件

- npm 账号已登录（`npm whoami` 验证），需开通 2FA
- GitHub 仓库 `knqiufan/pulse-line` 有推送权限
- 工作目录在项目根 `D:\code\status-bar-cc`

## 一、发布前检查

```bash
# 1. 确认在 main 分支，无未提交改动
git status
git log --oneline -5

# 2. 确认包名可用（仅首次发布需要）
npm view pulse-line 2>&1

# 3. 确认构建通过
npm run build
```

## 二、更新版本号

```bash
# 根据改动类型选择：
npm version patch   # 1.0.0 → 1.0.1  小修复
npm version minor   # 1.0.0 → 1.1.0  新功能
npm version major   # 1.0.0 → 2.0.0  破坏性变更

# npm version 会自动：
# - 更新 package.json 的 version 字段
# - 创建 git tag（如 v1.0.1）
# - 提交 version bump
```

## 三、预览打包内容

```bash
npm pack --dry-run
```

检查：
- 确认 `bin/pulse-line.js` 在打包列表中
- 确认 `.claude-plugin/` 目录在打包列表中
- 确认 `commands/`、`skills/` 在打包列表中
- 确认不包含源码（`src/*.ts`）、测试配置等不需要的文件

如果打包内容有问题，修改 `package.json` 的 `files` 字段：

```json
"files": [
  "dist/",
  "bin/",
  "commands/",
  ".claude-plugin/",
  "skills/"
]
```

## 四、GitHub 发布

```bash
# 推送代码和 tag
git push origin main
git push origin --tags
```

## 五、npm 发布

```bash
# 发布到 npm（需要 2FA 验证码）
npm publish --otp=<6位验证码>
```

发布成功后验证：

```bash
# 验证包可安装
npm view pulse-line version

# 验证 npx 可执行（在其他目录测试）
cd /tmp && npx -y pulse-line@latest --help
```

## 六、GitHub Release（可选）

```bash
# 创建 GitHub Release
git log --oneline $(git describe --tags --abbrev=0 2>/dev/null || echo v1.0.0)..HEAD

gh release create v1.0.1 \
  --title "v1.0.1" \
  --notes "## Changes
- xxx
- xxx"
```

## 发布后验证清单

| 检查项 | 验证方式 |
|--------|----------|
| npm 包可安装 | `npm install -g pulse-line` |
| npx 可用 | `npx -y pulse-line@latest` |
| CLI 可用 | `pulse-line --help` |

## 常见问题

### npm publish 报 403 (2FA)

```
npm error 403 Two-factor authentication required
```

解决：发布时加上 `--otp=<验证码>`。

### bin 文件被 npm 移除

```
npm warn publish "bin[pulse-line]" script name bin/pulse-line.js was invalid and removed
```

原因：`bin/pulse-line.js` 包含 CRLF 换行符。修复：

```bash
sed -i 's/\r$//' bin/pulse-line.js
```

### 包名已被占用

```
npm error 404 Not Found - GET https://registry.npmjs.org/pulse-line
```

如果返回已有版本信息而非 404，说明包名被占用。需更换包名或联系占用者。

### 本地链接测试

在发布前可本地测试包的行为：

```bash
# 在项目目录
npm link

# 然后在其他目录
cd /tmp
mkdir test-pulse && cd test-pulse
echo '{"cwd":"'$(pwd)'","session_id":"test-123","model":"test","context_window":{"current_usage":{}}}' | pulse-line
```
