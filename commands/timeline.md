# Tool Timeline

## Command

```
/pulse-line:timeline
```

## Description

Show recent Claude Code tool-call events collected by Pulse Line hooks.

## Instructions

Run the following shell command:

```bash
npx -y pulse-line@latest timeline
```

Useful variants:

```bash
npx -y pulse-line@latest timeline --last 10
npx -y pulse-line@latest timeline --json
npx -y pulse-line@latest timeline clear
```
