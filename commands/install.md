# Install Claude Pulse

## Command

```
/claude-pulse:install
```

## Description

Initialize claude-pulse in your Claude Code user settings. After installation, restart Claude Code to see the status bar.

## Instructions

Run the following shell command:

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/claude-pulse.js" install
```

Then tell the user to restart Claude Code for the status bar to take effect.
